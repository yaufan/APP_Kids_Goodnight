# 晚安小鎮

給 **2～5 歲**的小朋友，在台灣，國語為主：睡前最後 5～8 分鐘的安靜 APP，目的是**帶往睡覺**，不是玩。獨立的 APP，不是小小生活家的一部分。

- 設計：[docs/design.md](docs/design.md)，草圖在 `docs/mockups/`。
- 和「畫畫小鎮」「字母寵物」「動物小餐廳」「小卡認天下」「想一想樂園」「眼尖尖大挑戰」「迷宮小冒險」「小小生活家」是兄弟 APP：同一個作者、同一套技術、不同畫風。
- 不連網、不定位、沒有廣告、沒有帳號。
