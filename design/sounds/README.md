# 晚安小鎮的聲音

全部用 `make_sounds.py`（numpy）合成，寫進 `app/assets/sounds/`（16 kHz、單聲道）。都很小聲、很慢；沒有「叮！」「答對了！」。每個聲音有自己的亂數（用名字當種子），重新產生會一模一樣；長的聲音都是無縫循環。

```
python3 make_sounds.py          # 全部
python3 make_sounds.py rain     # 只做這幾個
```

| 檔案 | 什麼時候 | 怎麼做的 |
|---|---|---|
| `amb_dusk` | 關燈巡邏一開始：黃昏的街聲 | 風（濾波的雜訊慢慢起伏）＋蟲鳴（4.5 kHz 的短叫聲）＋遠遠的機車經過一次 |
| `amb_quiet` | 關掉三分之一的燈以後 | 風＋少一點的蟲鳴 |
| `amb_wind` | 關掉三分之二以後、數羊、故事、呼吸 | 只剩很輕的風 |
| `musicbox_1` | 搖籃曲：音樂盒（第一晚） | 《小星星》，正弦波加泛音和衰減做出音樂盒的叮叮聲，低音輕輕陪著 |
| `musicbox_2` | 音樂盒（第二晚） | 布拉姆斯《搖籃曲》 |
| `musicbox_3` | 音樂盒（第三晚） | 自己寫的五聲音階搖籃曲 |
| `humming_1`、`humming_2` | 搖籃曲：哼歌 | 像人哼「嗯～」：幾個泛音、鼻音的共振、慢慢的抖音；布拉姆斯和自己寫的那首 |
| `rain` | 雨聲 | 高頻的沙沙聲＋一顆一顆的雨滴＋低低的雨聲 |
| `waves` | 海浪 | 每 8 秒一個浪，慢慢湧上來再退下去 |
| `fan` | 風扇（完整版） | 穩定的風聲＋一點馬達聲 |
| `heartbeat` | 心跳（完整版） | 每分鐘 60 下的「咚、咚」，悶悶的 |
| `tap` | 按鈕 | 很輕的木頭聲 |
| `puff`、`puff_soft` | 關燈（像吹熄蠟燭）、點到已經暗的窗戶 | 短短的氣音 |
| `yawn_cat`、`yawn_rabbit`、`yawn_bear`、`yawn_duck`、`yawn_pig`、`yawn_owl`、`yawn_dog`、`yawn_sheep` | 動物睡著前打哈欠 | 先吸一口氣，再「哈～」：音高慢慢往下，每隻的音高和母音不一樣（小熊低低的、貓咪細細的、貓頭鷹「呼～」） |
| `yawn_small` | 晚安清單點了一項 | 小小的哈欠 |
| `sheep_hop` | 小羊跳過柵欄落地 | 軟軟的「咚」 |
| `baa` | 小羊趴下 | 小聲的「咩～」 |
| `page` | 故事翻頁 | 沙沙 |
| `breath_in`、`breath_out` | 按住月亮吸氣（4 秒）、放開吐氣（6 秒） | 一點點風聲，變大、變小 |
| `goodnight` | 「換你去睡了，晚安」 | 音樂盒三個音往下走 |

全部約 12 MB。
